# Student Record and Result Management System

A console-based, menu-driven **Student Record and Result Management System** written in C. It stores student details and SGPA for eight semesters, calculates CGPA, and includes a small rule-based **AI-Assisted Academic Advisor** that gives advice based on a student's CGPA.

This project is part of a C programming assignment that also introduces the practical use of AI tools and GitHub in software development.

## Features

- Console-based and menu-driven, written in C
- Maintains records of any number of students (the array grows automatically with `realloc`)
- Add a student, with checks for a duplicate SAP ID and for valid year (1 to 4) and semester (1 to 8)
- Search for a student by SAP ID and display the full record
- Calculate the CGPA of each student as the **average of the available SGPA values**
- Calculate the **average CGPA of each year** (1st to 4th year)
- Display the records of all students
- Delete an individual student record
- Display all records in **increasing order of SAP ID**
- Display all records in **increasing order of Name**
- **Academic Advisor** that generates a recommendation from the CGPA using if-else statements
- Records are saved to a file and loaded again when the program starts

## AI-Assisted Academic Advisor

The advisor does **not** connect to ChatGPT or any AI API. An AI tool was used to design the advice categories, and the final recommendation is generated by the C program itself, using if-else statements on the student's CGPA.

| CGPA | Category | Advice shown |
|---|---|---|
| 9.0 and above | Excellent Performance | Maintain your current study pattern |
| 7.5 to below 9.0 | Good Performance | Keep revising and strengthen weaker subjects |
| 6.0 to below 7.5 | Needs Improvement | Focus on subjects with lower SGPA (the program names the lowest-SGPA semester) |
| Below 6.0 | Requires Immediate Attention | Meet the faculty mentor and revise the basics |

The advisor also compares the latest SGPA with the previous one and shows whether the student is improving or slipping.

The decision logic lives in the `giveAdvice()` function:

```c
if (p->CGPA >= 9.0) {
    /* Excellent Performance */
} else if (p->CGPA >= 7.5) {
    /* Good Performance */
} else if (p->CGPA >= 6.0) {
    /* Needs Improvement */
} else {
    /* Requires Immediate Attention */
}
```

## Data Storage

Records are stored in memory in a dynamic array of structures. They are also saved to a binary file, `students.dat`, in the folder where the program is run:

- `saveToFile()` uses `fwrite` and is called after a student is added or deleted.
- `loadFromFile()` uses `fread` and is called once when the program starts.

If the structure is changed later, an old `students.dat` is ignored with a message; delete it and re-enter the records.

## How the Program Works

- **Array of structures:** every student is one `struct Student`, and all students are kept in `struct Student *s`, with `count` students stored.
- **Dynamic growth:** when the array is full, `realloc` doubles its size, so there is no fixed limit on students.
- **CGPA:** the sum of the SGPAs from semester 1 up to the current semester, divided by the number of those semesters.
- **Sorting:** the display functions copy the records and bubble-sort the copy, so the stored order is not changed. SAP IDs are compared as numbers and names with `strcmp()`.
- **Input safety:** an invalid menu choice such as letters is cleared with `getchar()` and shows "Invalid Choice" instead of looping forever.
